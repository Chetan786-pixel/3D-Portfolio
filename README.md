# 🌌 3D Portfolio — Cinematic Scroll Experience

A modern interactive **3D portfolio website** built with **HTML, CSS, JavaScript, and Vite**.

The portfolio uses **251 high-quality animation frames** and smooth scroll-based frame transitions to create a cinematic 3D experience while exploring the portfolio.
